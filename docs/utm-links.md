# Ready-made UTM Campaign Links (for the Owner / Marketing)

Every link below is copy-paste ready. Add one of these to emails, YouTube descriptions,
social posts, WhatsApp broadcasts or printed material, and the site attributes the visitor
and any enquiry they send to that source.

## How the links work

```
https://sarvadnyainfotech.com/<page>?utm_source=<source>[&utm_medium=<how>][&utm_campaign=<what>]
```

- `utm_source` — REQUIRED. Which channel the visitor came from. Must use a code from the table below.
- `utm_medium` — OPTIONAL. How it was delivered: `email`, `social`, `cpc`, `organic`, `offline`.
- `utm_campaign` — OPTIONAL. What you are promoting: lowercase, no spaces (e.g. `august_newsletter`).

All parameters are lowercase, no spaces, no commas. Only change the values inside `<...>`.

| Code | Means | Medium to use |
|---|---|---|
| `email` | Email / newsletter | `email` |
| `youtube` | YouTube channel / video | `social` |
| `facebook` | Facebook page or post | `social` |
| `facebook_ads` | Facebook / Meta paid ads | `cpc` |
| `instagram` | Instagram | `social` |
| `linkedin` | LinkedIn | `social` |
| `linkedin_ads` | LinkedIn paid ads | `cpc` |
| `whatsapp` | WhatsApp broadcast / chat | `social` |
| `google_ads` | Google paid search / display | `cpc` |
| `google` | Google organic search | `organic` |
| `google_maps` | Google Maps / Business Profile | `organic` |
| `justdial` | JustDial listing / ad | `organic` |
| `indiamart` | IndiaMART listing / lead | `organic` |
| `referral` | Someone recommended you | `referral` |
| `partner` | Business partner / reseller | `referral` |
| `qr` | QR code on card / flyer | `offline` |
| `offline` | Trade show, direct visit, any offline | `offline` |
| `direct` | Typed the URL directly | `direct` |

## How the site uses these links

- A visitor who arrives with a UTM link is tagged with that attribution on their visitor
  session (source, medium, campaign, term, content).
- If the visitor submits an enquiry form, the attribution is stored with the submission
  and shown to the internal team in the enquiry email (Source row).
- `utm_source` is the only required value; the others are optional and only used for deeper
  reporting. Links that only carry `?utm_source=<code>` work exactly the same.

To add a new channel, keep the pattern and pick a code from the table above - code,
medium and campaign should always be lowercase with no spaces.
