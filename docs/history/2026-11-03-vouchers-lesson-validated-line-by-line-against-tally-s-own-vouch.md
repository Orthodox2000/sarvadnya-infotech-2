# 2026-11-03 — Vouchers lesson validated line by line against Tally's own "Vouchers in TallyPrime" page

| Area | Detail |
| :--- | :--- |
| **Why** | The owner pasted Tally Solutions' published page (`tallysolutions.com`, updated **28 Aug 2025**) and asked for the lesson to be validated against it - add what the page has and remove what it contradicts. |
| **What the old lesson got wrong** | It flattened every voucher into a single table, so the three families Tally actually documents were invisible. It listed **8 vouchers** and omitted Physical Stock, Delivery Note, Receipt Note, Material In, Material Out, Purchase Order and Sales Order. It also effectively claimed Sales/Purchase need inventory enabled - they work in a company with only accounting enabled; stock moves only in invoice mode. |
| **What replaced it** | `lib/learn-tally-curriculum.ts` body now mirrors Tally's three families: **accounting** (Contra F4, Payment F5, Receipt F6, Journal F7, Sales F8, Purchase F9, Debit Note Alt+F5, Credit Note Alt+F6), **inventory** (Physical Stock Ctrl+F7, Stock Journal Alt+F7, Delivery Note Alt+F8, Receipt Note Alt+F9, Material In / Material Out via F10, plus Rejection In Ctrl+F6 / Rejection Out Ctrl+F5) and **order** (Purchase Order Ctrl+F9, Sales Order Ctrl+F8). |
| **Detail added from the source only** | Payment: cheque printing from the voucher, **Banking > Cheque Printing** list, **500+ supported banks**, Payment Advice to the supplier. Receipt: pending-invoice prompt, cash/cheque/NEFT/RTGS, instrument number, email to customer. Contra: cash deposit slip **with note denominations**. Journal: also used for credit purchases/sales. Credit Note: original invoice reference and the party's invoice list. Debit Note: voucher or invoice form when inventory value changes. Delivery Note: transporter, lorry number, dispatch document number, bill of lading, also called a delivery challan. Physical Stock: monthly/quarterly/yearly verification against book stock. Order vouchers: part fulfilment, balance tracking, pre-closure. A **"Choosing the mode"** section documents invoice / accounting-invoice / As-voucher, the toggle conversion and F12 extra detail fields. |
| **Shortcuts** | Taken from the set already pinned in the shortcut lesson (`Learn-Tally` curriculum) rather than invented. Material In / Material Out carry **F10 (voucher type list)** because no default shortcut is published for them. |
| **Metadata** | `seoDescription` widened to all three families; keywords gained `inventory vouchers in tally prime`, `order voucher in tally prime`, `delivery note voucher in tally`. FAQs rewritten to the new taxonomy and extended with family difference, delivery challan and order-shortcut questions (four new entries; the existing three kept). |
| **Corrected after the rewrite** | The "Common mistakes" bullet no longer implies Sales needs inventory: it now says stock moves only in invoice mode. The order-voucher paragraph no longer calls Delivery Note part of the order family - Purchase/Sales Order record the commitment, Delivery/Receipt Note record the goods. |
| **Verified** | The `bodyMd` string parses (`new Function` on the source line - 7,483 chars, **10 headings**, 21 table lines) and every shortcut row is present. No typecheck, build, dev server or `check:*` suite was run (standing single-pass directive). File is static, so this ships with the next deploy. |
