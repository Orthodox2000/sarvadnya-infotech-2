| **Root cause** | The 2026-10-29 "action-first" rewrite was executed as **verb-first**, which moved the searcher's own words out of the head of the snippet: `tallycloudaccess` (372 imps, 0 clicks) was answered with "Access TallyPrime From Anywhere"; the 223-impression voucher cluster with "Record Vouchers in Tally Prime"; `how to lock tally data for previous year` (58, pos 1.8) with "Lock Data in TallyPrime: How To"; `tally prime 7.2` (169, 0 clicks) with "Latest Version of Tally Prime 7.2"; `ledger master in tally prime` (34) with "Create Ledgers & Groups in Tally". |
| **Rule documented** | **The head of the title must be the query; the action goes in the tail.** `How to` belongs at the front when the query has it (it is part of the phrase). The qualifier people type — "Previous Year", "Navi Mumbai", "7.2", "GSTIN" — must be in the title, because that is the bolded text. The 25-char brand suffix is the disposable tail; a 62-char title loses the suffix, not the query, and `scripts/seo-audit.mjs` already treats that as a non-fatal WARN. |
| **Code (16 URLs)** | 8 lesson `seoTitle`s in `lib/learn-tally-curriculum.ts` (vouchers-types-contra, shortcuts-complete-list, latest-version, tally-gst, masters-ledgers-groups, how-to-create-company, cost-centre, erp9-vs-prime) plus `/cloud`, `/cloud/tallycloudaccess`, `/products`, `/about`, `/hrms`, `/services`, `/tutorials`, `/tools/tss-expiry-checker`. `/about` now leads with the company name, so `seoMetadata()`'s `alreadyBranded` check drops the duplicate suffix — the bare-brand query (`sarvadnya`, 228 imps, 0 clicks, pos 6.0) was only seeing the name in the truncated tail. `/services` ranks **position 1.78 with 0 clicks**; `/products`, `/hrms`, `/tutorials` had no query words at all. |
| **Database (11 URLs)** | `/news/[slug]` reads `seoTitle` + `description` from MongoDB, so `scripts/seed_news.mjs` alone changes nothing live. New **`scripts/update-news-seo.mjs`** (dry-run default, `--apply`) writes **only** those two fields, on an explicit slug allow-list, refuses to run when a slug is missing from the seed or when two posts would share a title, and imports the values from the seed so there is no second copy to drift. `scripts/seed_news.mjs` now `export`s `posts` and calls `seed()` **only when run directly** (`import.meta.url === pathToFileURL(argv[1])`), so importing it cannot open a Mongo connection or reseed the cluster. The 11 slugs: how-to-lock-data-in-tallyprime, tally-tss-expiry-meaning, how-to-add-gst-number-in-tally-erp-9, tally-cloud-access, what-is-tally-capital, how-to-check-tss-expiry-date-tallyprime, cbd-belapur-it-companies-list, it-companies-in-belapur, tally-tss-renewal-2026, plus **tallyprime-international-licenses** (94 imps, 1 click, **position 3.79** — the worst CTR of any page ranking in the top four) and **tally-5-star-partner-mumbai** (18 imps, 0 clicks, pos 5.83, missing the typed "Mumbai" from its own query `tally 5 star partner in mumbai`), both of which also had descriptions **over the 160-char limit** (165 and 184) so the click reason was cut mid-sentence. The 5-star title keeps 3 Star before 5 Star deliberately — the post's 2026-10-26 correction is that Sarvadnya is a 3 star partner, so the title must not read as a 5 star claim. |
