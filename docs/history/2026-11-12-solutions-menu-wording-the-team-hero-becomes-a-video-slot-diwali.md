| **Autoplay / error-free loop** | `<video autoPlay loop muted playsInline preload="metadata" disablePictureInPicture controls={false} poster=…>` + a `play()` call whose promise rejection is swallowed (iOS low-power mode and some mobile browsers reject autoplay even when muted — the unhandled rejection was the only realistic "error"). `visibilitychange` pauses the clip when the tab is hidden and resumes on return, so a background tab stops decoding. `prefers-reduced-motion: reduce` swaps the `<video>` for the poster `<img>` before any video bytes are needed. `onError` swaps in `content.hero_image` when that field holds a real photo, so an existing team photo is never lost. |

The admin panel's team editor still offers an image picker only; making `hero_video` editable is a **nested-repo** task, not done here. |
