## 1. AI API Upgrades & Chain-of-Thought (<think>) Stripping

**Goal:** Transition to larger, more performant open source LLMs and implement sanitization logic to clean up reasoning/chain-of-thought outputs from the user interface.

### Model Upgrades
- **Strategic Insight API (`app/api/ai/strategic-insight/route.ts`):** Upgraded model to `openai/gpt-oss-120b` (previously `llama-3.3-70b-versatile`).
- **Chat API (`app/api/chat/route.ts`):** Upgraded `PRIMARY_MODEL` to `openai/gpt-oss-120b` (previously `llama-3.3-70b-versatile`) and `FALLBACK_MODEL` to `qwen/qwen3-32b` (previously `llama-3.1-8b-instant`).
- **Search Recommendations & Summaries (`app/api/search/route.ts`):** Upgraded models to `qwen/qwen3-32b` (previously `llama-3.1-8b-instant`).

### Sanitization of Chain-of-Thought Logs
Since high-performance reasoning models outputs frequently contain internal `<think>...</think>` blocks, a robust regex cleaning pipeline was implemented across all AI routes:
- Added `.replace(/<think>[\s\S]*?<\/think>/g, '').trim()` to strip out reasoning tokens prior to sending responses to the client. This ensures the visual chat, search overview, and strategic advisory cards remain clean, professional, and free of internal reasoning blocks.

### Prompt Hardening
- **Rules Added:** `"Never mention free consultations, contact us, or promotional CTAs. Never use emojis."`
- **Link Optimization:** Removed the fallback `[[Contact Page|/contact]]` suggestion to align with strict non-promotional and clean point-based response guidelines.

## 3. QuickSupportModal — Letter-by-Letter Animation & Typing Engine

**File:** `app/components/QuickSupportModal.tsx` & `app/globals.css`

### Upgraded Typing Effect (Line-by-Line Chunking + Character Popping)
- **Before:** The assistant streamed text word-by-word with standard `setTimeout` intervals.
- **After:** Overhauled the `typeMessage` helper to split incoming text by newlines (`\n`). Characters are processed in chunks of 4 with a ultra-fast 7ms delay to create a high-performance streaming illusion.
- **Character Wrapping:** Map each individual character to a `<span className="letter-animate">` tag. Non-breaking spaces are handled natively via `\u00A0` mapping.

### CSS Keyframes (Globals.css)
Added smooth cinematic pop keyframes for streaming chatbot messages:
```css
.letter-animate {
  display: inline-block;
  animation: letterPop 300ms cubic-bezier(0.22, 1, 0.36, 1) both;
}

@keyframes letterPop {
  from {
    opacity: 0;
    transform: scale(0.3);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}
```
