## Changes Made

### 1. lib/tutorial-matcher.ts — AI Tutorial Matching Engine (NEW)
- **Keyword extraction** with stop-word filtering (50+ conversational filler words removed).
- **Synonym expansion map** — 13 synonym groups: invoice↔billing↔sale↔voucher, tax↔gst↔filing, bank↔banking↔reconciliation↔brs↔cheque, payroll↔salary↔employee↔pf↔esi, inventory↔stock↔godown↔batch↔barcode, report↔analysis↔balance sheet, shortcut↔keyboard↔hotkey, cloud↔hosting↔remote↔server, setup↔install↔configure, backup↔restore↔recovery, error↔issue↔problem↔fix, company↔firm↔business.
- **Scoring algorithm** — Exact title phrase (50pt), title keyword match (10pt), title synonym match (4pt), tag match (15pt), tag synonym (6pt), folder match (8pt), description keyword (4pt), description synonym (2pt).
- **Configurable thresholds** — `minScore: 5` (down from 8), `maxResults: 4` (up from 3) for broader matching.

### 2. app/(site)/learn-sara/page.tsx — Complete Chatbot Redesign
- **Immersive chat UI**: Full-screen layout (`h-screen` with dynamic `fixed` positioning below sticky header), no page header/footer, hidden scrollbar.
- **Welcome message**: Benefit-driven greeting — "Hi! I'm Sara. I help small businesses simplify their accounting, billing, and taxes so you can focus on growing."
- **Typing indicator**: Three bouncing dots with `1.2s` duration and staggered delays (0ms, 200ms, 400ms) for natural rhythm.
- **Smooth message animations**: `slideUp 0.5s cubic-bezier(0.16,1,0.3,1)` — soft deceleration curve instead of harsh ease-out.
- **Bot/User avatars**: Circular avatars on each message (green bot icon, gray user silhouette).
- **Timestamps**: Formatted `HH:MM` on every message bubble.
- **Tutorial suggestions**: Shown on every assistant response that has matches — "Related tutorials" card with thumbnail, title, folder, and arrow.
- **Quick-reply chips**: Horizontal pill buttons for follow-up topics, with hover→green fill + scale transition.
- **Quick topic grid**: Full topic list shown only at start, hidden after first interaction.
- **Body scroll lock**: `document.body.style.overflow = 'hidden'` on mount, restored on unmount.
- **Dynamic header offset**: Container pins `top` to sticky header's `getBoundingClientRect().bottom`, re-measures at 200ms/600ms and on resize for collapsible productbar.
- **Improved topic matching**: Scored matching instead of `.find()` — scores label keywords (5pt), answer keywords (2pt), follow-up keywords (3pt), threshold 5. Shows topic chips on fallback.
- **Helpful fallback**: Lists what Sara can help with (accounting, billing, GST, inventory, banking, payroll, reports, shortcuts) instead of "I'm focused on TallyPrime topics".

### 3. app/(site)/learn-sara/page.tsx — Animation Softening

- **Match after response**: `findMatchingTutorials()` called with user's query text after AI response typing completes.

- **Message interface extended**: Added `suggestedTutorials?: Tutorial[]` field.

### 5. app/(site)/learn-sara/page.tsx — Scroll & Layout Fixes
- **Scroll container ref**: Direct `el.scrollTop = el.scrollHeight` instead of unreliable `scrollIntoView({ behavior: 'smooth' })`.
- **Double-pass scroll**: Immediate `scrollTop` + `requestAnimationFrame` second pass for late-rendered content.
- **80ms safety net**: `setTimeout(scrollToBottom, 80)` for edge cases.
- **Hidden scrollbar**: `no-scrollbar` class from `globals.css` applied to chat area.
- **Fixed positioning**: Container uses `fixed left-0 right-0 bottom-0` with dynamic `top` for bulletproof viewport locking.

### 6. lib/tutorial-matcher.ts — Improvements
- **Synonym expansion**: `expandKeywords()` inflates query keywords with related terms before scoring.
- **Conversational stop words**: Added "want", "need", "like", "know", "tell", "show", "help", "make", "get", "use", "try", "thing", "anything", "something".
- **Lower threshold**: `minScore` dropped from 8 → 5 for more permissive matching.
- **More results**: `maxResults` increased from 3 → 4.
