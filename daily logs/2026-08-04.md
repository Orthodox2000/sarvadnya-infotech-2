# Daily Log — 4 August 2026

## Email Config Simplified — Unified Per-Page Recipients (no more dual structure)

### Problem
The admin email-config page had **two overlapping structures**: the legacy "Recipients per Form Type"
(quote/enquire/support/callback/demo/general/tss-renewal) and the newer "Per-Page Destinations" flat list.
Users found it confusing which one controlled what. Also, the inline sidebar enquiry forms on product/cloud/HRMS
pages still posted to `/api/contact` which only **saved** submissions — it never sent an email and ignored the
per-page destination system, so those forms had no DB-controlled recipient.

### Solution
1. **One merged editor:** the admin page now shows a single "Recipients by Page" section grouped by enquiry
   category — Products / Services / Cloud / Modules / Other Pages — sorted per page with the route path shown
   under each label and one receiver input per page. The legacy per-form-type editor was removed from the UI
   (its server-side fallback stays for submissions with no page destination).
2. **Inline sidebar forms now email per-page:** `/api/contact` resolves the destination from the body
   `destination` or the `Referer` URL, saves the submission, then calls `sendEmailDirect()` inline with
   `requestId` dedupe + rate limiting. Unknown pages keep the old save-only behavior.
3. **replyTo safety:** `sendInternalFormCopy()` only sets `replyTo` when the submitted email is valid — enquiry
   forms that collect a phone number instead of an email no longer risk a Resend rejection.

### Routing model after the change (single)
- `UnifiedContactModal` → `POST /api/email/submit` with `destination = prop ?? getDestinationFromPath(route)`.
- Inline sidebar forms → `POST /api/contact`, destination resolved server-side from body/Referer.
- Recipients come **only** from the DB setting `EMAIL_DESTINATION_RECIPIENTS` (admin-managed). Blank page = saved but no email (opt-in). `demo` pre-wired by bootstrap.
- Legacy `EMAIL_FORM_RECIPIENTS` → `RESEND_INTERNAL_TO` fallback applies only to submissions with no page destination at all.
