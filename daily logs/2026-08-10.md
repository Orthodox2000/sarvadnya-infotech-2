### 2. Sara AI — Factual Correctness Overhaul (TSS Renewal)
- **Reported bug:** Learn Sara answered "how to renew TSS" with a **fictional** "TSS Renewal" menu
  in Gateway of Tally and a fake "TSS" toggle in Company Features, and pointed at a route that the
  user could not find ("no such options present").
- **Root cause:** the LLM (Gemini/Groq) was free to invent menu paths because the system prompt
  lacked verified Tally facts. `matchTopic()` had no TSS topic, so queries fell through to the AI.
- **Fixes applied, then corrected again after the user supplied verified facts** (first pass wrongly
  asserted "no TSS menu inside Tally" — replaced):
  - `app/api/chat/route.ts` **LEARN_SYSTEM_PROMPT**:
    - Added `FACTUAL ACCURACY — NON-NEGOTIABLE` block — only give menu paths/shortcuts known to be
      real; teach only from the verified `TALLYPRIME KNOWLEDGE` list; when the user reports a missing
      option, never invent a second path — ask what's on screen and offer the team; never quote
      unsure rupee amounts/tax rates/deadlines; never mock typos like "newnew".
    - Added verified **"Create a new company"** steps (Gateway of Tally > Create Company > enter
      Company Name/Address/State/Financial Year/Books from > Ctrl+A).
    - Rewrote the **TSS (Tally Software Service)** section with the verified renewal flow:
      - TSS works on **all** licenses (Silver, Gold, Server) — never say "Gold or higher".
      - **Yes, you CAN renew from inside TallyPrime:** `Alt+R` (Manage TSS Renewal) on the Gateway
        of Tally (appears ~15 days before expiry), or `F1 (Help) > Settings > License > Manage
        License` then `F9 (Renew TSS)`.
      - Either path opens the Tally Solutions renewal portal in the browser with serial + billing
        pre-filled; pick 1 Year or 2 Years (10% discount); validity syncs back into Tally (About page).
      - Red expiry warning appears ~15 days before expiry; renewing **before** expiry grants +1 month.
      - When red/expired these stop: e-invoicing & e-way bill generation, GST auto-download
        (GSTR-2A/2B) + direct filing, banking (direct payments, auto-BRS), Remote Access/WhatsApp
        (mobile/browser reports, WhatsApp invoice sharing) — offline data entry keeps working.
      - If the option isn't visible, ask what they see (shortcut only shows when renewal is due) and
        offer the partner route as fallback (`[[Renew TSS|/services/tss]]`).
      - Reply in the user's language (Marathi/Hindi/etc.) with identical facts.
    - Updated **SALES_SYSTEM_PROMPT** TSS catalog line — renewal possible from inside Tally (paths
      above) or via us by serial number; TSS works on all licenses.
  - `lib/sara-topics.ts`:
    - Added **"TSS Renewal & Subscription"** topic (with follow-ups "What stops when TSS expires?"
      and "No TSS option visible?") carrying the verified renewal flow + `[[Renew TSS|/services/tss]]`.
    - Added a TSS pattern to `getTeachingFallbackResponse()` and `getFallbackResponse()`:
      `/\btss\b|subscription|renew(?!.*amc)|serial\s*number/` (AMC-guarded via negative lookahead).
    - First-pass answers that claimed "no TSS menu inside Tally" were fully replaced with the
      verified in-Tally renewal steps.
