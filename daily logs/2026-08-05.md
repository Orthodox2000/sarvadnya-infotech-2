# Daily Log — 5 August 2026

## cPanel Static Landing Frontend + Vercel Backend (deployment trial)

### Problem
Goal: deploy the site to **cPanel** via direct file upload. The pasted "Next.js static export" checklist
did not fit this project — Sarvadnya Infotech is a **full-stack Next.js 15 app** (37 API route handlers,
`app/actions/careers.ts` server action, MongoDB, Resend, Groq/Gemini, Vercel Blob, Mega) that cannot be
statically exported (`output: 'export'` fails on route handlers + server actions; pages render live DB
data; `redirects()`/`headers()`/`images.remotePatterns` are ignored or unsupported under export).

Decision (confirmed with the user): keep **Vercel as the backend** and ship an **uploadable static
frontend to cPanel** that calls the live Vercel APIs — a working backup/mirror front with a real
enquiry form and live Ask Sara chat, without requiring Node or MongoDB on the shared host.

### Solution
Two parts:

**Part A — Vercel backend (1 new file):** added `middleware.ts` (app root, `matcher: ['/api/:path*']`)
that adds CORS to the public API routes: answers `OPTIONS` preflight with 204, echoes
`Access-Control-Allow-Origin` for origins in the `FRONTEND_ALLOWED_ORIGINS` allowlist env, and always
allows `localhost`/`127.0.0.1` for local preview. No route handlers were touched; admin routes remain
session-guarded. Needs a one-time deploy + env var to go live.

**Part B — `cpanel-landing/` (new standalone static project):** a minimal Next.js 15 static export
(`output: 'export'`, `trailingSlash: true`) producing a ~1.1 MB `out/` folder:

- **Landing page** (`app/page.tsx`): sticky nav, hero ("Tally that works as hard as your business"),
  8-card services grid, 3 flagship products (TallyDrive / TallyCapital / TallyPrime), Why Us, contact
  section, dark footer — real branding (Certified Tally Partner since 2008, 1500+ businesses,
  +91 98213 09060, info@sarvadnyainfotech.com, wa.me link), blue/sky/white Tailwind v4 theme.
- **EnquiryForm** (client) → `POST {API_BASE}/api/email/submit` with
  `{ name, email, contact, service, description, formType: 'landing', destination: 'contact',
  requestId: crypto.randomUUID() }` + success/error states (exactly-once dedupe via requestId).
- **ChatWidget** (client) → floating Ask Sara → `POST {API_BASE}/api/chat` `{ messages, mode: 'sales' }`,
  renders `[[Label|/url]]` tokens as links to the live Vercel site, offline fallback with phone/email.
- **`lib/api.ts`** — `API_BASE` / `SITE_BASE` (default `https://sarvadnya-infotech.vercel.app`,
  overridable via `NEXT_PUBLIC_*`).
- **`public/`** — `logo.png`/`logo.svg` (copied from root) + `.htaccess` (Apache trailing-slash rewrite,
  auto-copied into `out/` by Next export).
- **`DEPLOYMENT.md`** — full manual: build, Vercel deploy + `FRONTEND_ALLOWED_ORIGINS`, zip contents of
  `out/` → cPanel File Manager → extract into `public_html`, 9-point post-upload test battery,
  troubleshooting table, update/rollback procedures, API contracts.

**Root project change:** `tsconfig.json` — added `"cpanel-landing"` to `exclude` so the root `tsc`
no longer type-checks the standalone mini app (its own tsconfig uses `@/* → cpanel-landing/*`).

### Architecture after the change
- cPanel (static `out/`) → JSON `fetch` (CORS via middleware) → Vercel `/api/email/submit` + `/api/chat`.
- All env secrets, Mongo, Resend, AI keys stay on Vercel; cPanel serves files only.
- Deep links (Enquire / Book a Demo / product & service cards) open the live Vercel site in a new tab.
