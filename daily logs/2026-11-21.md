## 3. Admin-added learning video invisible — mixed `createdAt` sort + edge cache

Owner: *"i also added a video thru admin about bank import tool but it doesn't appear on frontend."*

- Read-only diagnosis: the row **was** in the frontend cluster (`sarvadnya.zvdcpsj.mongodb.net` / `test`), `_id 6b0162f40d5782aed9f14129`, created `2026-11-21T09:23:00.537Z`, but its `createdAt` was an **ISO string** while the six older rows held real BSON Dates. Mongo orders String below Date, so `sort({ createdAt: -1 })` returned it 7th of 7 — last, so it looked absent.
- Second cause: `ff96b6e` had added `PUBLIC_API_CACHE` (`s-maxage=3600`) to `/api/tutorials` and the exact-path CDN allowlist in `next.config.js`; a sort fix alone would still have been hidden for up to an hour.
- **`lib/mongodb-utils.ts`** — `fetchTutorials()` no longer sorts in Mongo. It fetches all rows, normalises `createdAt` to an epoch number (`Date`, ISO string, missing/invalid → `0`) and sorts in JS before `serializeData()`. No data migration.
- **`app/api/tutorials/route.ts`** — returns `Cache-Control: no-store`; `/api/tutorials` was removed from the `next.config.js` allowlist so the global `/api/:path*` no-store rule wins. Seven/eight rows make a fresh read negligible.
- Cluster mapping refined: the custom domain reads the root `.env` cluster; **both** Vercel aliases read a different, stale 6-row cluster. New learning content must be written to the root cluster. Live read after the follow-up insert showed **8** entries on `www.sarvadnyainfotech.com`.
