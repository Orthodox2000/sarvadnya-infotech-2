## 3. Overflow Clipping — Removed Site-Wide

### Files Modified
- `app/globals.css` — removed `overflow-x: clip` from `html` AND `body`
- `app/layout.tsx` — removed `overflow-x-hidden` class from both `<html>` and `<body>`

### Rationale

**`html { overflow-x: clip }` → REMOVED**
- `overflow-x: clip` on `html` propagates to the viewport, which clips ALL fixed-position descendants
- Was causing support buttons at the right edge to be clipped to ~20% of their actual size on hero page
- Fixed-position children like QuickSupportModal and SupportButton need viewport-relative positioning without ancestor clipping

**`body { overflow-x: clip }` → REMOVED (dead code)**
- Was overridden by the `overflow-x-hidden` Tailwind class on `<body>` in layout.tsx (class selector beats element selector)
- Removed for cleanup

**`html/body overflow-x-hidden` → REMOVED**
- When using "Request Desktop View" on mobile, the viewport width exceeds the screen width
- `overflow-x: hidden` was clipping right-edge content (hero visuals, buttons) that should be visible
- Sections that need overflow control already have `overflow-hidden` at the component level (HomeHero, etc.)
