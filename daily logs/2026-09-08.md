## SEO: VideoObject Missing-Thumbnail Fix (commit `e37bfb1`)

### Issue
- The homepage `VideoObject` JSON-LD in `lib/seo.ts` referenced `public/video-thumbnail.png`, but that file did **not** exist. Google cannot index a video without a crawlable `thumbnailUrl`, so the hero-video rich result was invalid.

### Fix
- **`public/video-thumbnail.png` (NEW)** — 1280×720 teal-branded thumbnail frame (150,873 bytes) matching the mobile hero video's look, so the schema asset becomes crawlable.
- **`lib/seo.ts`** — `uploadDate` aligned to the source media file's mtime so the recorder date is truthful (recency signals in SERP).

### Note
- The homepage background videos (`/sarvadnya-mobile.mp4`, per-slide desktop mp4) themselves were not changed here — only their schema/thumbnail indexing.
