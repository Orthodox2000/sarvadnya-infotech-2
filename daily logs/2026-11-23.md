## 1. Thank-you email — real company logo, hosted image, no CC

Owner: *"for thankyou template, abiove logo isnt of company logo and it fails to render as imae in thankyou email., also thankyou email doesnt need to have a cc for anyone, so remove it as well or unselect CC for it only"*, followed by *"this is error"* pointing at the `<img src="cid:sarvadnya-logo" width="240" height="51" …>` tag.

- **Wrong image:** the acknowledgement inherited the shared transactional header, which renders `public/TallyCertificate.png` — the Tally certificate banner used by the navbar/signature — at 240×51. The company's own mark is `public/logo.png` (256×256, already used by JSON-LD, the favicon and the checkout receipt).
- **Broken render:** live sends passed `{ cid: 'sarvadnya-logo' }` with a Resend inline attachment. The SDK maps `contentId → content_id`, but the image still failed in the received mail. The thank-you path now uses a normal absolute HTTPS URL (`${siteUrl}/logo.png`) and no `cid:`/attachment at all.
- **Correct size:** `email-templates/email-brand.mjs` now accepts `logoWidth`/`logoHeight` on `renderBrandHeader()` and exports `EMAIL_COMPANY_LOGO_WIDTH = EMAIL_COMPANY_LOGO_HEIGHT = 64`. `email-autoreply.mjs` passes those only for this receipt, so other templates keep the 240×51 certificate banner. `.d.mts` siblings updated.
- **Cross-origin:** added a CORP/CORS exemption for `/logo.png` in `next.config.js` alongside the existing `/TallyCertificate.png` rule, so the hosted image can load in webmail clients.
- **No CC:** removed the `getGlobalCc()` call and the `cc` field from `sendClientAutoreply()` in `lib/email.ts`. The acknowledgement has no CC regardless of admin settings; the internal copy and careers mails keep their destination-scoped global CC.
- **Preview:** `scripts/email-preview.mjs` now embeds `public/logo.png`; `public/email/preview-client-autoreply.html` and `.png` were regenerated with `npm run preview:email` using the system Chrome. Generated HTML: one data-URI image, zero `cid:sarvadnya-logo`, `width="64"`.
- Updated `email-templates/README.md`, `docs/ARCHITECTURE.md` §6, this daily log, tracker row 153 and `docs/history/2026-11-23-thank-you-logo-and-no-cc.md` + its `docs/HISTORY.md` headline row.

No build, dev server, typecheck or check suite (single-pass directive §3). Nested `sarvadnya-advanced/` untouched. Deploy the root repo before the live thank-you email changes take effect.
