### Summary of Changes

1. **Shared Knowledge Base** — Extracted `saraTopics` from learn-sara into `lib/sara-topics.ts`. Both Ask Sara (floating button) and Learn Sara (full-page) now use the same source of truth.

2. **AI-Powered Sales Consultant** — Sara is no longer a passive chatbot. The system prompt positions her as a senior sales consultant who proactively suggests products. Every response must: reference the user's words, mention a specific product by name, and end with a CTA.

3. **Full Product Catalog in AI** — The AI now knows about all 20+ offerings: TallyPrime Silver/Gold/Server, AWS/Windows/TallyCloudAccess/NoSky cloud solutions, AMC/Training/TDL/TSS/Mobile/WhatsApp services, TallyDrive, TallyCapital, HRMS, and all 6 industry modules (Logistics, C&F, Housing, Excel Import, Garment, Sales Commission).

4. **Performance Fix** — Removed per-character `<span>` rendering that was creating thousands of DOM nodes per message. Typewriter now uses larger chunks (20-40 chars) with shorter delays (5-8ms). Scroll polling reduced from 100ms to 300ms. Chat is now smooth on low-end devices.

5. **Stop/Interrupt Button** — Send button transforms into a red ■ square during AI response. Clicking it instantly shows the full text and re-enables input. Uses `AbortController` for fetch cancellation + `stopRequestedRef` for typewriter break.

6. **Input Focus Fixed** — Input bar stays focused during AI response. Only the send action is blocked, not typing. Users can compose their next message while Sara is still responding.

7. **Text Wrapping Fixed** — Added `break-words overflow-wrap-anywhere` to chat bubbles. Long words and URLs no longer get cut off.

8. **Bold Rendering Fixed** — Removed `.replace(/\*/g, '')` that was stripping `**bold**` markers before the renderer could process them. Product names now render bold as intended.

9. **Robust Think-Tag Cleanup** — API cleanup now handles all variations: `<think>`, unclosed `<think>`, `</think>`, `[think]`, `[[think]]`, malformed tags. Falls back to safe message if response is empty/short.

10. **Sitemap Updated** — 8 previously missing pages added. All public-facing pages now indexed.
