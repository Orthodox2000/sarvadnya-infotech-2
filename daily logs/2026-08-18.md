# Daily Log — 18 August 2026

## Video Hero Background, Dark-Mode Text, UTM Tracking, Reverse DNS, Excel Export & Policy Update

### 1. /demo Hero — Video Background with Dark Overlay
- `HomeHero.tsx` gained an optional **`backgroundVideo?: string`** prop. When provided, renders
  a muted autoplaying `<video>` (playsInline, loop, object-cover) as the absolute hero background
  **instead of** the static `bg.png` image. Default behaviour unchanged — no other pages affected.
- **Opacity 0.75** applied to the video element via inline style.
- **40% black overlay** (`bg-black/40`) layered on top for darkness/contrast.
- Decorative gradient blobs hidden when video bg is active to avoid visual noise.
- `<main>` background set to `bg-transparent` when video bg so the video shows through.

### 2. /demo Hero — Text Color Readability on Dark Video
- Introduced `isDark = !!backgroundVideo` flag. When active, **all hero text flips to
  white/light** for readability:
  - Badge: `bg-white/10` + `text-teal-200` (glassmorphic)
  - Title h1: `text-white` (both invisible sizing copy and visible rendered copy)
  - Highlight words: `text-teal-300` (was `text-[#006569]`)
  - Typing cursor: `bg-teal-300`
  - Description: `text-white/80`
  - Stats pills (Experience / Queries / MSMEs): `bg-white/10 border-white/20` glassmorphic
    with `text-white/70` labels and `text-white` bold values, icons `text-teal-300`
- Zero impact on the default light hero (all conditions gated on `isDark`).

### 3. /demo Layout — Navbar Gap Fix
- Added `pt-0` wrapper div around `<HomeHero>` in `demo/page.tsx` to remove top whitespace
  between the sticky navbar and the video hero. Iterated through `pt-32` → `pt-12` → `pt-4`
  → `pt-0` to match user feedback.
- Background section: restored `bg-white` on outer `<main>` in demo page (was removed during
  earlier pass).

### 4. /demo Hero — Image Synced with Real Homepage

### 5. AGENTS.md — 4 New Developer Rules
- **Never Assume** — always ask the user for clarification before proceeding with ambiguous
  requirements.
- **Minimal Code / Use Libraries** — prefer npm packages (xlsx, date-fns) over hand-rolled
  solutions.
- **Document All Changes** — every file edit must have a `// CHANGE:` comment or commit
  message explaining what and why.
- **Validate Before Completing** — re-read the original user request and verify every
  requirement is actually satisfied before marking done.

### 6. Data Collection — GPC/Privacy Gating Removed
- `lib/visitors.ts`: `recordVisitor()` no longer takes `respectGpc` — full data (IP, geo,
  reverse DNS, proxy/VPN/Tor) always stored. Added `reverseDns`, `isProxy`, `isVpn`, `isTor`
  to `GeoInfo`. Added `UtmParams` interface with `utm_source/medium/campaign/content/term`.
- `app/api/identify/route.ts`: GPC gating removed, fires async reverse DNS lookup after
  geo resolution.
- `app/api/email/submit/route.ts`: GPC gating removed, always stores full IP, captures UTM
  params, fires async reverse DNS.
- `app/api/contact/route.ts`: GPC gating removed, always stores full IP.

### 7. UTM Parameter Tracking
