### 5. Production Bug — Invalid Module Image URL
- **Console error** on `/modules`: `next/image` threw "Failed to construct URL" for
  `src="\assets\images\1519003722824-194d4455a60c.jpg"` (backslashes — invalid URL).
  The other console lines (COOP warning, HMR websocket, Vercel analytics debug) were dev-only noise.
- **Root cause:** the MongoDB `modules` record for `logistics-transport` had the image path stored
  with `\\` separators (legacy data). Fix applied directly to the DB:
  `image: "\assets\images\1519003722824-194d4455a60c.jpg"` → `/assets/images/1519003722824-194d4455a60c.jpg`.
  Verified the file exists on disk; all six module images now resolve.
