## Follow-Up Fixes (same session)

### 9. `/find-solution` — Blue Scheme Converted to Teal

  `shadow-blue-500/10, /20, blue-900/10 → shadow-teal-900/10, /20, /10`. No blue tokens remain
  (only the "Blueprint" button copy).

### 10. Ask Sara — Modal Now Opens on Client-Side Navigation
- **Root cause:** `/ask-sara` 307-redirects to `/?ask-sara=true`, but `SupportButton` (shared
  `(site)` layout) only checked the URL on mount. A direct visit worked (full reload), but clicking
  the AI-menu "Chat with Sara" `next/link` is a **soft navigation**: `/` → `/ask-sara` → `/` — the
  pathname never changes, so no effect re-run fired and the modal never opened.
- **Fix (`app/components/SupportButton.tsx`):** added a lightweight 400 ms URL poll plus
  `hashchange`/`popstate` handlers, and `history.replaceState` strips the `ask-sara=true` param once
  fired so closing the modal doesn't instantly re-trigger it.

### 11. Learn Sara — `*emphasis*` Now Renders Bold
- The teaching model (Gemini/Groq) sometimes emits single-asterisk `*tally*`; `SaraText` only
  handled `**double**`, so single-asterisk text showed literally.
- **Fix (`app/components/SaraText.tsx`):** added a `\*[^*\s][^*]*\*` alternative to the inline
  tokenizer and a render branch that bolds `*text*` too (guarded so `* spaced *` and bullets stay
  literal). Benefits Ask Sara and Learn Sara.

### 12. `/search` — Google-Style Starting Page
- No-query visits now show a Google-homepage-style landing: centered Sarvadnya Infotech wordmark +
  "Site Search", a long pill search bar (magnifier, clear button, teal Search CTA, autofocus), quick
  action chips (Site Search / Ask Sara), a **Quick Reference** row of page chips (products, cloud,
  services, modules, HRMS, tutorials, find-solution, careers, contact) and **Popular Searches**
  chips that run the search on click. The results view gained a compact Google-style search bar in
  its header for refining. Query handling unchanged (`/api/search`).
