### 1. Module Deep-Links → `#fragment` Anchors (commit `16702a4`)
- **Why:** GSC flagged `/modules?id=cf-agencies` as a separate crawled URL (canonical → `/modules`). URL fragments are never sent to the server, so they can never be indexed separately.
- `lib/product-nav.ts`, `app/components/Footer.tsx`, `app/components/QuickAccessHubDemo.tsx` → `?id=` links converted to `/modules#cf-agencies`.

### 2. noindex 4 Utility Pages + Drop from Sitemap (commit `7e96d13`)
- `lib/seo.ts` — `seoMetadata()` gained optional `noindex?: boolean` (emits `robots: { index: false, follow: false }`).
- `/search` + `/learn-sara` layouts set `noindex: true`; `/demo` + `/theme-settings` pages export explicit `robots: { index: false, follow: false }`.
- `app/sitemap.ts` — `/search`, `/demo`, `/learn-sara` removed from the routes array.
- **Why:** `/demo` is an exact homepage clone ("Duplicate without user-selected canonical"), the others are thin JS-only/dev tools; this thins the "Crawled/Discovered – currently not indexed" rows.
