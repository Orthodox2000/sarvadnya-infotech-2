The mobile layout was touch-reactive: it reused the desktop `hovered` JS state + CSS `:hover`, but touch devices have no real hover — taps and scroll finger contact fire `mouseenter`/`mouseleave` erratically, leaving the state stuck (card lifted + ring, others dimmed) until a card is tapped.
