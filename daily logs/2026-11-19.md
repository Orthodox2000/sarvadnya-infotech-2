## §1 — Fluid CPU: middleware was the Edge deployment

The only Edge function in the public deployment is `middleware.ts`. Its catch-all matcher fired on
every request except `_next/static` and `_next/image` — so all public assets (69 images, 15 MB of
video, 19 MB of PDFs, fonts, `llms.txt`) and every other `_next/*` request consumed Fluid CPU in
iad1. Node routes were correctly configured (11 explicit `runtime = 'nodejs'`; Next 15 defaults
the rest to nodejs) and `proxy.ts` is inert — confirmed against the installed Next 15.5.29
constants (`MIDDLEWARE_FILENAME = 'middleware'`, no `PROXY_FILENAME`).

Matcher narrowed to documents + `/api/*`, with an explicit static-extension exclusion list so
dotted slugs such as `/news/tallyprime-7.2` still receive the canonical/410/admin logic. The Vercel
dashboard itself was not accessible, so the bill drop must be confirmed after deploy.

## §2 — Fonts

Downloaded Geist (latin, variable 100–900) and Playfair Display (latin, variable 400–900) from
Google's own CSS into `app/fonts/`. `next/font/google` replaced by `next/font/local` in
`app/layout.tsx`, preserving both CSS variables — zero changes needed in pages or Tailwind.
Google Fonts remains a fallback in three places: each `localFont`'s `fallback` array, a stylesheet
+ preconnects in `<head>`, and the explicit stacks in `globals.css`. CSP `style-src` allows
`fonts.googleapis.com` for that fallback sheet only.

## §3 — Images

`scripts/compress-images.mjs` (npm: `optimize:images`) re-encoded 59 rasters in place with sharp:
68.5 MB → 20.7 MB (−69.7%). Names unchanged because they are a public contract (TSX, Tailwind
backgrounds, seeded Mongo docs, JSON-LD, email HTML). The two SEO-sensitive share/poster assets
were skipped. New `cardbg.webp` / `mobilebg.webp` replaced the two heavy CSS backgrounds on four
pages, and raw `<img>` tags gained lazy/eager loading + async decoding.
